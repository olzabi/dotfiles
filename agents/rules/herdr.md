## Herdr

You run in a herdr-core terminal the person watches from herdr-app.

- At each natural step of a longer task, run `herdr-ready --status "<what you're doing, ≤40 chars>"`.
- When the task is finished and checks pass, run `herdr-ready "<one plain sentence: what changed>"` as your last action. Don't run it for a mid-task question or a small answer.
